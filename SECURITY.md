# Politique de sécurité

Bonk écrit sur des disques entiers : une faille peut détruire des données. Merci de signaler toute vulnérabilité en privé, sans ouvrir d'issue publique qui la décrirait.

## Signaler une vulnérabilité

Utilisez le [formulaire de signalement privé de GitHub](https://github.com/FantasmaGlad/Bonk/security/advisories/new). Si le formulaire n'est pas disponible, ouvrez une issue qui demande un moyen de contact privé, sans aucun détail sur la faille.

Indiquez si possible la version de Bonk, le système, les étapes pour reproduire et l'effet observé. N'y joignez ni image disque personnelle ni donnée identifiant votre matériel.

## Traitement

Le projet est maintenu par une seule personne, sur son temps libre. Objectifs, sans garantie :

- accusé de réception sous 7 jours ;
- première évaluation sous 30 jours ;
- divulgation coordonnée (coordinated disclosure) : l'avis est publié avec le correctif, au plus tard 90 jours après le signalement sauf accord contraire.

## Versions suivies

Seule la dernière version publiée reçoit des correctifs de sécurité.

## Périmètre

Sont concernés le code de ce dépôt, ses binaires publiés et ses workflows. Une vulnérabilité d'une dépendance se signale d'abord à son projet ; prévenez-nous si elle touche Bonk.
